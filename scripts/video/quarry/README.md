# Ролик «Каменоломня» (09.11)

Объясняющий ролик по механике Каменоломни, как ролик о разбитом корабле: 2:25, 1920×1080, 30 к/с. Настоящие экраны
игры во весь кадр с плавным наездом на нужное место, золотой кружок в точке нажатия, плашка «кто на экране»
(администратор, капитан, участник), заставка и концовка шрифтами игры (Philosopher, Literata).
Озвучка — выбранный голос из «Моих голосов» ElevenLabs (`voice_id txnCCHHGKmYIwrn7HfHQ`, `eleven_v3`, с пометками ударений),
текст и музыка `quarry-main` — `scripts/voice/lines-quarry.json`, запуск — workflow `voice.yml` (этапы `tts,music`), результат — ветка `voice-tts`.

Сборка (рабочая папка `R` вне репозитория):
1. Локальная партия: API на :3000 (собранный `apps/api`), из `apps/api` с переменными `.env`:
   `LOCAL_PASS=<пароль локальных учёток> SEED=67016126 node ../../scripts/video/quarry/setup.mjs` — партия «Весенний сезон»,
   команды «Ковчег» и «Странники» по шесть участников с вымышленными именами, «Ковчег» доведён до прибрежного города Исход.
   После — перезапустить API (кэш карт команд).
2. Экраны: `G=<id партии> OUT=R/cap LOCAL_PASS=… node ../../scripts/video/quarry/capture.mjs`, затем `capture-wreck.mjs`
   (корабль с камнями). Снимки 1280×720 при масштабе 1,5 = 1920×1080, точки нажатий — `R/cap/shots.json`. Мостимая и
   «возвращённая» дороги в `capture.mjs` выбраны под карту зерна 67016126.
   **Карту сдвигать коротким быстрым жестом и только на заметное расстояние**: долгое нажатие на месте ставит метку команды.
3. Голос: `git archive origin/voice-tts | tar -x -C R/audio/vt`, обрезка тишины по краям (ffmpeg `silenceremove`, как в «Осени»)
   → `R/audio/lines/sN.wav` и `durations.txt`.
4. `R=… python3 timeline.py` (data.js), `node render.mjs preview 3,15,23` — проверочные кадры в `R/prev`,
   `node render.mjs video 0 145.32 R/video-only.mp4`, `R=… python3 mix.py` (`R/mix.wav`), затем сведение видео и звука ffmpeg.
