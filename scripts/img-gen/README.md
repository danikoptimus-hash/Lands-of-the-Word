# Генерация картинок для игры

Ключ OpenAI хранится как сетевой секрет облачной среды Claude для `api.openai.com` — прокси подставляет его в запросы сам.
Переменная окружения не нужна, ключ в чат и репозиторий не попадает. Никогда не просить ключ у владельца (см. `CLAUDE.md`).

- `gen_img.py "<промт>" out.png [--size …] [--quality …] [--bg green|transparent|none] [--model gpt-image-2]` — одна картинка.
  Потоковый режим обязателен: прокси обрывает долгие запросы. Для спрайтов — `--bg green` + `key.py` (вырезка по хромакею: альфа по расстоянию до цвета углов, обрезка,
  уменьшение, webp); `--bg transparent` модель `gpt-image-2` не поддерживает (ответ «Transparent background is not supported»).
- `key.py src.png dst.webp <ширина>` — спрайт из картинки на зелёном фоне.
- Текстуры и пейзажи — `--bg none`, затем `PIL` → webp (`quality` 80–88).

Примеры промтов и что чем сделано — в `docs/LANDS_OF_THE_WORD.md` (замок, свеча, пергамент, кирпичи стены, остров
Каменоломни, значки наград, круглый город Бытия).
