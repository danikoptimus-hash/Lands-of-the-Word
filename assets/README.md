# Картинки игры

Структура:

| Папка | Что кладём | Кто |
|---|---|---|
| `reference/` | Три утверждённых эталона стиля (`walled_city.png`, `terrain_desert.png`, `start_babylon.png`) | Владелец |
| `raw/terrain/` | Текстуры местности, оригиналы из генератора, 1024×1024 | Владелец |
| `raw/city/` | Типы городов, оригиналы, PNG с прозрачностью | Владелец |
| `raw/start/` | Стартовые локации, оригиналы | Владелец |
| `raw/props/` | Декор и объекты, оригиналы | Владелец |
| `processed/` | Обработанные: обрезка, приглушение цвета, атласы, сжатие. Генерируется скриптом | Помощник (скриптом) |

## Как загрузить через GitHub

1. Открой папку в репозитории (например `assets/raw/terrain/`), кнопка **Add file → Upload files**.
2. Перетащи PNG-файлы. Имена — как в промпте: `terrain_hills.png`, `village.png`, `start_egypt.png`. До 25 файлов за раз, до 25 MB каждый.
3. Внизу — «Commit changes» прямо в ветку `claude/lands-word-city-conquest-6xtei9` (выбери «Commit directly to the … branch»).
4. Рядом с картинками можно положить текстовый файл `prompts.txt` с промптами, которыми они получены.

Оригиналы в `raw/` не редактируем руками: всё, что нужно поправить, делает скрипт обработки, чтобы можно было перегенерировать.
