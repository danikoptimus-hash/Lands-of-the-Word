# Сравнение движков на одной сцене

Решение владельца 13.11: движок для версии 2 выбирается не по таблице, а по одной и той же сцене,
собранной в Godot, Unity и Unreal и показанной на его ноутбуке. Правила приёмки — в `CLAUDE.md`.

## Что одинаково во всех трёх

- **Место.** Настоящий участок: западный берег Корфу у Палеокастрицы, квадрат 11 × 11 км. Высоты — открытые
  данные (Terrain Tiles, AWS Open Data), дно достроено по расстоянию до берега.
- **Покров.** Карты «скала / деревья / кусты / пляж» и карта пород — из одной основы.
- **Расстановка.** Правило, а не список: `osnova/rasstanovka.py`. Каждый движок повторяет его у себя и получает
  те же точки (около 1,1 млн деревьев, 1,6 млн кустов, 6 тыс. камней).
- **Модели.** Свободные (CC0) с Poly Haven: деревья `island_tree_01`, `island_tree_02` (похожи на оливу),
  `jacaranda_tree`, `pine_tree_01`, `tree_small_02`; кусты `searsia_lucida`, `searsia_burchellii`,
  `wild_rooibos_bush`; берег и скалы `coastal_cliff_01/02/04`, `coast_rocks_*`, `coast_land_rocks_*`.
  Кипариса в свободных библиотеках нет — в первой версии сцены его не будет.
- **Небо.** Три состояния: ясный день, закат, шторм. Облака, свет и воду даёт сам движок (или его готовое
  дополнение) — это и сравнивается.
- **Камера и замер.** Один пролёт: весь участок с высоты → бухта → 150 м над кронами; счётчик кадров на
  ноутбуке владельца.

## Образцы для сверки

Лист с настоящими аэроснимками места и семью признаками приёмки отправлен владельцу 13.11
(адрес — в журнале сеанса). Кадр из движка проходит, если отдельный проверяющий находит в нём все признаки.

## Папки

- `osnova/make.py` — основа сцены: скачивает высоты, строит дно и карты. Результат — `osnova/dannye/`
  (`vysoty.png`, `maski.png`, `porody.png`, `opisanie.json`, контрольные картинки).
- `osnova/rasstanovka.py` — правило расстановки и его проверка (число точек, картинка участка).

Запуск (нужны numpy, Pillow, scipy — в рабочей среде они в `scratchpad/gdvenv`):

    python sravnenie/osnova/make.py
    python sravnenie/osnova/rasstanovka.py

## Итог (14.11)

**Владелец решил остаться на Godot.** Unreal 5.8 на его ноутбуке (встроенная графика Arc 140V) на пустой карте
шаблона в редакторе дал 27 кадров в секунду при качестве Maximum и 41 при Medium, а нужно 60 — с лесом и морем
в запасе. Облака Unreal «из коробки» владелец назвал «шикарными»: это утверждённая планка облаков для Godot.
Unity не пробовали (его готовые облака и вода — в тяжёлом режиме HDRP; оценка, не замер).

## Состояние

- Основа сцены — работает.
- Godot (`godot/`): земля через Terrain3D, четыре материала, море из игры — работает; леса нет. Сцена — испытательная
  площадка для облаков, леса и материалов.
- **Облака (14.11).** Их рисует само небо: шейдер из Godot Volumetric Cloud Demo (clayjohn, MIT) с нашими правками
  (`godot/src/nebo.gdshader`, помечены словом «ПРАВКА»): облака доходят до горизонта и тонут в дымке; насыщенность
  синевы и светлая дымка у горизонта подобраны по кадрам Unreal владельца; яркость облаков; уровень качества
  (половина или четверть разрешения, число шагов луча). Облака всегда выше камеры, теней от облаков нет —
  решения владельца. Дополнение SunshineClouds2 убрано: на встроенной графике Intel не работает.
- **Образец для владельца.** Без ключа `--kadry` сцена открывается на весь экран: полёт (W A S D, E, Q, правая кнопка
  мыши), 1–3 — небо, 4 — качество облаков, 5 — угол зрения, 6 — разрешение, 7 — земля и море, счётчик кадров.
- Unreal: сцена не собиралась; задание для сеанса на ноутбуке владельца — `unreal/ZADANIE.md` (не понадобилось).
- Unity: не начат.
