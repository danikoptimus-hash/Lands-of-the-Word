# Аудит интерфейса игрока — «Земли Слова»

**Дата:** 2026-09-11. **Объём:** все экраны, которые видит игрок (не админ), в `apps/web/src`.
**Цель владельца:** «максимально интуитивный и минималистичный интерфейс, единый стиль на телефоне и компьютере, проработать каждую страницу, блок, символ, надпись — буквально без пропусков».

Правила документа: имена реальных людей не упоминаются; где поведение продукта не очевидно из кода или главного документа — стоит пометка **❓ вопрос**, а не выдуманное правило. Ссылки на код — `файл:строка` относительно `apps/web/src/` (для сервера — `apps/api/src/`).

Обозначения приоритета в разделе 4: **P0** — обязательно (ошибки, обрывы навигации, нечитаемое), **P1** — нужно (единый стиль и словарь), **P2** — желательно.

### 2.3 Тон и обращение

- Обращение «вы» практически везде; **единственное «ты»**: `Дела ждут на карте: нажми на метку у дороги.` (`TeamPage:230`). В словаре мёртвые ключи с «ты»: `Пока нет игр. Создай первую.` (`i18n.en.ts:110`), `Пока ничего не взято. Нажми…` (`:111`). Решение: «вы» везде.
- Стилизация под старину («вести», «столица», «хранители», «руины») используется точечно и не выдержана: рядом «push-уведомления», «SMTP», «админ». Решение: нейтральный современный тон, игровые слова — только для игровых сущностей (город, столица, испытание, претенденты/хранители, разведчик/пророк/посол/летописец).
- Восклицательные тосты (`Город ваш!`, `Вызов брошен! Отрывок выдан`, `Верно! Знак шифра: X`) — допустимы как награда, но не для новостей об угрозе.
- Длинные абзацы-объяснения правил внутри форм (`BattlePanel:61,118,220`, `PushToggle:44-48`, `ForgotPage:25-26`) — заменить на одну строку + «Подробнее» (раскрывающаяся справка), чтобы интерфейс был минималистичным.

- **Тёмная тема** отсутствует (`color-scheme` не задан); карта тёмная, интерфейс светлый — при ночном использовании контраст резкий. ❓ В-19 — нужна ли тёмная тема.

### 2.6 Модель навигации игрока

```
/login ── регистрация/вход ──► /  (Мои команды · [Мои игры админа])
                                │ тап по команде
                                ▼
                       /games/:id/team  (без шапки)
                        ├─ игра не начата: карточка + «← Мои игры»   ← нет аккаунта/выхода
                        ├─ карта: HUD · язычок «›» · свайп от края
                        │     └─ меню: дела · испытания · положение · проходы · состав · push
                        │            └─ Мои игры · Аккаунт · Выйти
                        └─ попап города / sheet дела
/account ── «‹ Мои игры» (не «назад на карту»)
/join/:token ──► /games/:id/team
/forgot, /reset ── «← Ко входу»
```

Проблемы:
1. Три разных «назад»: `.crumb` с иконкой (Account), текст `← …` (Forgot/пред-старт), ghost `‹ К районам` (попап). Один компонент.
2. С карты в аккаунт — 2 тапа (язычок → плитка), обратно — 2 тапа (крошка → карточка команды). Нет прямого «на карту» из аккаунта.
3. Состояния без шапки (ошибка, загрузка, «игра не начата») — тупики.
4. Вход в меню на компьютере — узкий язычок; на телефоне — скрытый жест.
5. Игрок с одной командой при каждом входе попадает на список, а не на карту (❓ В-20 — редиректить на единственную команду?).
6. Нет страницы/раздела «Как играть» — правила разбросаны по подсказкам внутри форм.

### 2.7 Трудно обнаружить

- Свайп от левого края для меню; язычок `›`.
- Что означают ★, 🌊, 🏰, 🔭, цвета меток и сторон (нет легенды).
- Способности ролей (разведка, подсказка пророка, посол) — кнопки появляются только у носителя роли и только в определённом месте; остальные не знают, что роли что-то дают.
- «Перенести столицу» — только для капитана, только внутри попапа взятого города.
- Правило времени чтения — в `title`.
- Формула «положения команд».
- Что происходит после сдачи дела (кто проверяет, когда откроется узел) — сказано одной строкой в sheet.
- Что делать с шифром (конверт, адресат) — становится ясно только после решения всех заданий.
