# Дизайн-система «Земли Слова» — решения редизайна (сентябрь 2026)

Основание: аудиты `audit-player.md`, `audit-admin.md`, `audit-styles.md` и скриншоты всех экранов на 412px и 1280px.
Цель владельца: максимально интуитивный и минималистичный интерфейс, единый стиль на телефоне и компьютере, проработать каждую деталь.
Формат: по каждому аспекту — за / против / решение. Решения обязательны для всех, кто правит `apps/web`.

## 0. Принципы

1. **Один экран — одно главное действие.** Всё остальное вторично (secondary/ghost) или спрятано в меню «⋯».
2. **Слова вместо жаргона.** Игрок и администратор видят слова из правил игры, не из кода: перекрёсток, сторона, дело, задание, город, столица, испытание, конверт, шифр, ключ.
3. **Показывать, а не объяснять.** Абзацы-инструкции внутри форм заменяются подписью в одну строку или подсказкой «?» по требованию.
4. **Одна форма — одно поведение.** Одинаковые вещи выглядят и ведут себя одинаково на всех страницах (кнопка «назад», состояния загрузки/пустоты/ошибки, подтверждения, тосты, аватары команд, статусы).
5. **Телефон и компьютер — одно приложение.** Один DOM, одни компоненты; на компьютере лишь больше места: боковое меню команды становится колонкой, панель города — колонкой рядом с картой. Никаких «десктопных» экранов с другой логикой.
6. **Тап-цель не меньше 44×44.** Визуально элемент может быть меньше, зона нажатия — нет.
7. **Обращение на «вы»**, а лучше — безлично («Карта ещё не создана» + кнопка). Игровой словарь — только для игровых сущностей.
8. **Ни одного эмодзи и текстового глифа** в интерфейсе: только `Icon`. Эмодзи остаются в тексте писем и push (там нет иконок).

## 1. Терминология (единый словарь)

| Понятие | Слово | Не использовать |
|---|---|---|
| учётная запись | аккаунт | учётка |
| адрес почты | почта (EN: email) | Email, e-mail в русском |
| тот, кто ведёт игру | администратор | админ, организатор, владелец платформы (для игрока: «администратор игры») |
| вершина карты | перекрёсток; пустой — развилка; точка старта — старт | узел, вектор, точка |
| ребро с делом | сторона | путь, дорога, ребро |
| задание на стороне | дело; результат — сдача | задание (для дел) |
| задание в городе | задание; блок книги — район | — |
| статусы дела | свободно · в работе · на проверке · принято · возвращено | одобрено, вернули |
| соревнование за город | испытание; стороны — вызов (претенденты) и ответ (хранители); результат — город перешёл / устоял / вызов не завершён / отменено | битва, атака, оборона, война; женский род |
| уровень | уровень испытания | уровень защиты |
| захват свободного города | взять город | занять, открыть, присвоить (кроме тестового действия) |
| секреты города | шифр (называет команда адресату) → ключ (в конверте) | код, ключ конверта |
| человек с конвертом | адресат | семья (как общее слово) |
| печать | ярлык на конверт, вкладыш | — |
| повторяемость дела | повторяемое / однократное | уникальное, дублируется |
| сложность дела | сложность 1–3 (игроку не показывается) | тяжесть |
| стихи | стихов | ст. |
| закрыть форму | Отмена; панель — иконка `x` («Закрыть») | Скрыть, Свернуть |
| удалить | Удалить — сущность; Убрать — человека/связь | — |
| пустая игровая роль | Без роли | — |
| организация | церковь | организация (в подписи поля: «Церковь») |

Решение о «администраторе» (за: так называет себя владелец и так в правилах; против: «организатор» теплее) — оставляем **администратор**, полностью, без сокращения.

## 2. Токены

- **Цвет.** Палитра остаётся (пергамент `--bg #F6F4EF`, акцент `--accent #C7742A`, текст `#1F1B16`). Добавляются `--info #2F6FB3` и `--info-soft`, `--map-bg #2B2724`, `--map-fog #3F3A34`, `--map-paper #F3EAD3`. Удаляется `plum` и все цвета вне токенов. `--ok` → `--success`. Цвет несёт смысл только в статусах, предупреждениях и цветах команд; **цветные кромки карточек `data-tone` убираются** (за: различимость блоков; против: 6 цветов без значения, пестрота — решение: убрать).
- **Шрифт.** Одна шкала: `--fs-xs 12px`, `--fs-sm 13px`, `--fs-md 15px`, `--fs-lg 17px`, `--fs-xl 22px`. Заголовки: страница `h1` xl/700, секция `h2` lg/600, подсекция `h3` md/600. Инлайн `fontSize` запрещён.
- **Отступы.** `--sp-1 4px … --sp-6 32px`; инлайн `margin/padding` запрещены — есть утилиты `.mt-1…4`, `.stack` (вертикальный gap), `.row` (горизонтальный).
- **Радиусы/тени.** `--radius 12`, `--radius-sm 8`, `--radius-pill 999`, одна тень `--shadow`, одна для оверлеев `--shadow-lg`.
- **Контролы.** Три размера: `sm` 36px (только внутри строк списков и HUD), `md` 44px (по умолчанию), `lg` 52px (главная кнопка форм на телефоне). Ниже 44px — только с расширенной зоной тапа (`::before` 44px).
- **Движение.** Одна длительность `--dur 160ms`, `prefers-reduced-motion` уважается.

## 3. Компоненты (канон)

| Компонент | Решение |
|---|---|
| Кнопка | `primary` (заливка акцентом), `secondary` (белая с рамкой), `ghost` (без рамки), `danger` (красная заливка — только необратимое). Иконка слева, текст всегда (кроме иконочных кнопок с `aria-label`: закрыть, удалить, копировать, изменить, меню «⋯»). |
| Поле | одна высота 44, подпись сверху (`label`), подсказка снизу (`.hint`, одна строка), ошибка под полем. Числовые — `max-width: 12ch`. |
| Карточка | белая, без кромок; заголовок = иконка сущности + название + одно число. В шапке карточки не больше одной кнопки. |
| Список | `ListBlock`: заголовок → состояние (`loading` скелет / `empty` строка с иконкой / `error` «Не удалось загрузить · Повторить») → строки → строка добавления снизу. В строке одно видимое действие + меню «⋯». |
| Статус | пилюля с иконкой и цветом по единой палитре: нейтральный (свободно, черновик), info (в работе, идёт), warn (на проверке, ждём ответа), success (принято, разрешён, устоял, победитель), danger (возвращено, отказ, выбыла, перешёл-потерян). Без капса. |
| Команда | всегда кружок-аватар цвета команды с буквой + название. Залитые бейджи и цветные полосы убираются. |
| Назад | один компонент `Back` (иконка + подпись контекста): «Мои игры», «{название игры}», «К карте». |
| Вкладки | сегментированный контрол на всю ширину контейнера, одинаковый на телефоне и компьютере; на ширине < 600px — иконка над короткой подписью, все вкладки помещаются без прокрутки (не больше 6). |
| Оверлеи | шторка снизу (телефон) / панель или модал (компьютер) — один компонент `Sheet` с заголовком, `x` и телом; фон `--surface`, вложенные блоки `--surface-2`. |
| Тост | до 3 строк, ширина ≤ `calc(100vw − 32px)`, три тона (нейтральный / успех `check` / ошибка `alert`), тап закрывает, `role=status`. |
| Подтверждение | всегда заголовок-вопрос + одна строка последствий + кнопка-глагол; `danger` для необратимого. |
| Копирование | одно поле с кнопкой «Скопировать» → «Скопировано» + тост. |
| Иконки | `Icon` + новые: `lock`, `grip`, `arrow-up`, `arrow-down`, `menu`, `more` (⋯), `minus`, `zoom-in`, `zoom-out`, `camera`, `video`, `printer`, `trophy`, `hint`, `info`, `help`. Таблица «сущность → иконка»: игра `crown`, карта `map`, команда `users`, дело `scroll`, задание/город `city`, книга `book`, проверка `check`, испытание `wave`, проход `handshake`, спор `alert`, конверт/адресат `mail`, печать `printer`, настройки `settings`, аккаунт `user`, уведомления `bell`, итоги `trophy`. Иконку сущности не использовать для действия. |
| Даты | одна функция `fmtDate(iso)` по локали: «сегодня 14:05», «вчера 18:30», «5 сент., 14:05». |
| Склонение | `plural(n, ["команда","команды","команд"])` — все счётчики. |
| Локализация | каждая видимая строка через `t()`; словарь EN разбит на модули по областям. |

## 4. Каркас и навигация

- **Шапка** (все страницы, кроме карты): логотип + «Земли Слова» (без подписи «Lands of the Word»; на EN — «Lands of the Word»); справа — один элемент «аватар + имя» с выпадающим меню: Аккаунт · Аналитика (суперадмин) · Выйти. Бейдж «суперадмин» — только на странице аккаунта.
- **Гостевые страницы** (вход, восстановление, новый пароль, приглашение): один лэйаут с панорамой, переключателем RU/EN и карточкой 420px.
- **Главная.** Игрок с одной командой и без своих игр — сразу на карту. Иначе: «Мои команды» (карточки с пилюлей статуса игры) и, только если есть свои игры, «Мои игры». Создание игры — отдельная страница `/games/new`; ссылка «Создать игру» внизу. Пустое состояние для игрока: «Вас ещё не пригласили в команду. Попросите у капитана ссылку-приглашение.»
- **Страница команды** — полноэкранная карта. HUD слева сверху: кнопка «Меню» (иконка `menu`, 44×44, бейдж только для требующего действия: возвращённое дело, входящий запрос прохода, ваш ход в испытании) + аватар и название команды. Справа сверху: «Вся карта», «К старту» (`flag`), `+`/`−`. На ≥1024px меню — постоянная левая колонка 360px, карта справа; кнопка «Меню» скрыта. Служебные состояния (загрузка, ошибка, «игра не начата») — с шапкой и кнопками «Повторить» / «Мои игры».
- **Боковое меню команды**: Наши дела · Испытания (только сводка, без форм) · Положение команд (числа словами, без полосы-балла) · Проходы · Состав · Уведомления · внизу плитки Мои игры · Аккаунт · Как играть · Выйти.
- **Попап города** — `Sheet` с шапкой (иллюстрация, название книги, статус одной строкой, пилюля «Столица») и индикатором шагов «1 Порядок · 2 Районы · 3 Конверт»; ниже — тело шага; отдельные свёрнутые секции «Проход» (первой, если город чужой) и «Испытание». Один индикатор прогресса (районы).
- **Задание**: строка «Район 3 · Клятва Руфи · 1:15–18» + область «по этому району»; полоса чтения «Чтение 1:20 / 3:00 · счёт идёт, пока задание открыто»; счётчик «Попытка 1 из 2»; кнопка всегда «Ответить», причина неактивности — строкой над ней.
- **Страница игры (администратор)** — вкладки: Обзор · Карта · Команды · Дела · Проверка · Настройки (6, помещаются на телефоне иконками с подписью). **Обзор** = статусная страница: в черновике — чек-лист подготовки (Карта → Команды и приглашения → Дела → Адресаты конвертов и ярлыки → Начать игру) с переходами; в игре — «Ждёт проверки N», «Идёт испытаний N», положение команд, срок окончания, отдельный блок «Завершить игру» внизу; после — итоги. Конверты (адресаты + ярлыки) живут на Обзоре в шаге подготовки и остаются там во время игры. **Карта** — отдельная вкладка на всю ширину, панель перекрёстка — `Sheet` поверх карты (на компьютере — колонка справа), тестовые действия в свёрнутом разделе «Тестовые действия» с одним выбором команды. **Проверка** — четыре одинаковых блока (Сдачи · Испытания · Споры · Проходы-справочно, все всегда видны, пустые схлопнуты в строку), счётчик вкладки = сдачи + записи + споры. **Настройки** — форма всегда открыта (без режима «сводка/изменить»), группы «Игра», «Карта и старты», «Пожертвование», «Администраторы», «Уведомления».
- **Шапка страницы игры**: назад «Мои игры», название + пилюля статуса; счётчики убираются (числа есть на вкладках).

## 5. Решения по вопросам аудитов (владелец может изменить)

| Вопрос | Решение | Почему |
|---|---|---|
| Виден ли владелец города до решения заданий | оставить как есть (виден) | так реализовано и ожидается игроками; правило 2.5 — уточнить у владельца |
| Тяжесть дела игроку | не показывать | ни на что для игрока не влияет |
| Кто взял дело | показывать имя в карточке дела | команде полезно |
| Полоса-балл в положении команд | убрать | формула не из правил |
| Проходы в счётчике «Проверка» | не считать; блок справочный | у администратора нет действий |
| Тестовые действия на карте | свернуть в «Тестовые действия» | не смешивать с боевыми |
| Адресаты до старта | пункт чек-листа «желательно», не блокирует старт | ярлыки нужны к первому взятому городу |
| Минимум перекрёстков | 200 везде | так в настройках и на сервере |
| Один игрок — одна команда | сразу на карту | меньше шагов |
| Кнопки масштаба | добавить `+`/`−` | мышь без колеса, доступность |
| Тёмная тема | нет (пока) | отдельная задача |
| Ответ текстом на запрос прохода | добавить поле | API уже поддерживает |
| Раздел «Как играть» | добавить страницу с кратким текстом правил из главного документа | правила разбросаны по подсказкам |
| Отмена решения по сдаче | нет (тост с результатом) | не поддерживается сервером |

## 6. Порядок работ

1. Фундамент (токены, компоненты, шапка, иконки, утилиты, разбивка словаря и стилей на модули).
2. Гостевые страницы, главная, аккаунт, приглашение, «Как играть».
3. Игрок: карта, HUD, меню, карточка дела, попап города, задание, проход, испытание.
4. Администратор: страница игры и все блоки, карта, ярлыки, аналитика.
5. Серверные тексты, которые видит игрок: без жаргона, через `msg()`.
6. Скриншоты всех экранов на 412/1280, проверка тап-целей и контраста, деплой.
