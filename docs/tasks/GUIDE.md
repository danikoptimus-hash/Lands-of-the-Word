# Как составлять задания города (руководство для контента)

Контент города — файл `content/cities/<код книги>.json` (коды в `packages/domain/src/books.ts`). Образец — `content/cities/rut.json`. Проверка — `python3 scripts/validate-city.py content/cities/<код>.json`, файл принимается только со статусом «ОК»; каждое предупреждение нужно осмысленно проверить. Текст книги — `python3 scripts/verses.py <код> 2:1–7` (или `2`, `2–3`, `--find слово`). **Только Синодальный перевод, русская нумерация стихов, всё сверять по тексту, ничего не писать по памяти.**

## Формат

```json
{ "book": "rut", "title": "Руфь", "translation": "Синодальный перевод, русская нумерация стихов",
  "codeRule": "Каждый район даёт один знак шифра. Знаки по порядку районов — это шифр города, который называют семье с конвертом.",
  "districts": [ { "verses": "1:1–5", "title": "…", "summary": "…" } ],
  "tasks": [ { "scope": "district", "type": "choice", "prompt": "…", "options": ["…"], "correct": 0 } ] }
```

- `districts` идут в порядке книги; команда сначала расставляет их по порядку, потом решает по одному заданию на район. `tasks[i]` относится к `districts[i]`.
- `verses`: `1:1–5`, `1:16–2:3`, `12` (глава), `12–22` (главы). Тире «–».
- Типы заданий: `number` (`answer`), `text` (`answers`: все допустимые написания), `choice` (`options` 4 варианта, `correct` — индекс), `order` (`items` 4–7 пунктов в порядке текста).
- `scope`: `district` — по своему району; `group` + `groupDistricts` (номера районов с 1) — по нескольким; `book` — по всей книге.

## Сколько районов

| Размер книги | Районов |
|---|---|
| 1 глава | 4–6 |
| 2–6 глав | 6–9 |
| 7–16 глав | 9–13 |
| 17 и больше глав | 13–16 |

Район = сцена или смысловой блок, а не «глава». Скелет — краткое содержание из вступления учебной Библии (расшифровки), но границы уточняются по тексту. Большие книги: районы покрывают не всё подряд, а узловые события; у Псалтири и Притчей районы — тематические группы или знаменитые главы с точными ссылками.

## Район

- **Название**: короткое, образное, как название главы в романе («Шесть мер ячменя», «Сапог и свидетели»). Не заголовок из учебника.
- **Пересказ**: 1–3 предложения, что происходит. Описывает сцену так, чтобы её можно было узнать и поставить на место, но **не содержит ответа на задание этого района** — ни имени, ни числа, ни ключевого слова. Валидатор это проверяет.

## Задание

Цель: заставить открыть текст и прочитать внимательно. Задание — маленькая загадка летописца, а не вопрос из теста. Ставь читателя в положение наблюдателя сцены, цепляй за деталь, которую замечают только при чтении. Но ответ всегда **однозначен и короток**.

Хорошо:
- «На гумне в полночь один человек вздрогнул. Прочитайте 3:8–9 и напишите, что именно попросила Руфь простереть над собой» → text: `крыло` (+ варианты).
- «Ближайший родственник был готов купить поле, пока не услышал одно условие. Из чего он боялся расстроить свой удел? (4:5–6) Выберите ответ» → choice.
- «Соседки дали ребёнку имя, а книга тут же говорит, чьим отцом он стал. Кем этот мальчик приходится Давиду? (4:17)» → choice.
- «Расставьте по порядку, кого встретила Ноеминь на пути домой и что каждая сделала (1:8–18)» → order (пункты дословно из текста).

Плохо:
- «Как звали сына Руфи?», если район называется «Рождение Овида» (ответ в названии).
- «Вставьте пропущенное слово: “народ твой будет моим народом, и твой … моим Богом”» (угадывается без текста).
- Ответ длиннее трёх слов, ответ-фраза, ответ, зависящий от падежа.
- Вопрос без ссылки на стихи для `district` (ссылка «глава:стих» обязательна, чтобы команда открыла текст). Для `book` ссылки нет, но есть подсказка, где искать («в первой половине книги»).

Правила:
- Ответ `text` — одно слово или имя в именительном падеже; в `answers` перечислить падежи и написания, которые могут ввести (например `["Мара", "Марою", "Марой", "Мара"]`, `["крыло", "крылья", "крыла"]`).
- Пропущенные слова — только богословски значимые для книги, не «Бог», «Господь», «Израиль».
- `choice`: 4 варианта, отвлекающие — тоже из этой книги и правдоподобные; один верный.
- `order`: пункты — дословные короткие цитаты или имена в порядке появления в указанных стихах.
- `number`: число должно стоять в тексте или считаться прямо по указанным стихам (сколько имён в списке, сколько раз названо слово в отрывке). Не считать по всей книге без границ.
- Смешивать типы: в книге от 9 районов — не меньше двух заданий каждого типа; хотя бы два задания `group` или `book` (сопоставить два места книги).
- Никаких имён современных людей, ничего вне текста книги; толкования можно использовать только для выбора важных мест, не для ответов.
- Длина вопроса — до 350 знаков.

## Что делает игра сама

Шифр (по знаку за район) и ключ конверта генерируются при старте игры; в контенте их нет. Последний шаг города — назвать шифр адресату (семье, вдове, старице) и получить конверт — тоже делает игра, в контенте книги этого шага нет.
