# Шаблон главы экспертного заключения

Каждая глава — Markdown на русском, 3500–5000 слов качественного текста (не вода: механика, цифры, примеры, сценарии). Структура главы:

1. **Как есть** — что в игре уже реализовано по этой теме (только факты из документа и кода; если не уверены — пишите «предположительно»).
2. **Дыры и слабые места** — конкретные проблемы с разбором: пример ситуации, чем плохо, к чему приводит.
3. **Предложения** — пронумерованные, с префиксом главы (например S-01, S-02 …). Каждое предложение оформляется так:

```
### S-07. Короткое название

**Суть.** Одна-две фразы.
**Зачем.** Какую дыру закрывает или какой интерес добавляет.
**Как работает.** Правила, цифры, пример сценария с командами «Моряки» и «Берег» (только выдуманные названия команд, без имён людей).
**Риски и ограничения.** Что может пойти не так, как смягчить.
**Сложность:** S / M / L · **Влияние:** 1–5 · **Этап:** сейчас / следующий сезон / v2
```

4. **Иллюстрации.** Минимум 3 на главу. Иллюстрация — отдельный SVG-файл в `docs/proposals/audit-2026-09/img/<префикс>-<номер>.svg` (простая векторная схема: прямоугольники, стрелки, подписи; ширина 720, читаемый шрифт 14–16px, фон белый, палитра: тёмно-коричневый #3b2a1a, охра #c7742a, синий #2e627e, зелёный #4c7a3f, серый #6b645a). Вставляется в текст как `![подпись](img/s-01.svg)`. SVG должен быть валидным (проверьте `xmllint --noout`).

Правила:
- Никаких имён реальных людей нигде. Команды и игроки в примерах — вымышленные названия («Моряки», «Берег», «капитан», «участник»).
- Только Синодальный текст Библии, ссылки на места Писания — в русской нумерации.
- Игра для церковной молодёжи: предложения должны быть уместны (никакой азартной механики, никаких унижающих механик, всё воспитательно и по-доброму, но азартно в хорошем смысле).
- Пишите как эксперт для владельца проекта: прямо, конкретно, с цифрами и сценариями. Не повторяйте документ, а анализируйте.
- Не выдумывайте текущее состояние игры. Источники: `docs/LANDS_OF_THE_WORD.md` (главный документ: §2 правила, §2.8 битвы, §2.9 столицы, §2.14 дипломатия, §2.15 роли, §13 контент), `content/deeds-default.json` (стандартный набор дел), `content/cities/*.json` (задания городов; пример — `content/cities/rut.json`), код правил: `apps/api/src/routes/*.ts`, `apps/api/src/services/*.ts`.
