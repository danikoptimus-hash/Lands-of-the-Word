Формат: пункт отчёта → решение → что делать (код / документ).

## Глава 1, раздел 3 (расхождения документа и кода)

- 3.1 Владелец города виден сразу → **оставить как в коде**: владелец и его команда видны, как только команда дошла до города. Документ §2.5 переписать (два пункта про «не видит, занят ли город»). I-02 закрыто.
- 3.2 Момент T → **как в коде**: T фиксируется отправкой капитана, растёт после возвратов; дедлайн ответа от одобрения администратором. Документ: §2.8 п. 6 и формула в §5.1.
- 3.3 Минимальное T = 60 с → **оставить**, блиц — законная тактика. S-02 и «минимум» из B-01 сняты.
- 3.4 Возврат после дедлайна → **исход не должен зависеть от времени проверки**: часы стороны останавливаются на время проверки (при возврате дедлайн сдвигается на длительность проверки), симметрично для претендентов (14 дней) и хранителей (T). Если отправили после дедлайна — потеря без сдвига. Код + документ.
- 3.5 Уступка города → **убрать кнопку и механику целиком**. Код (маршрут, кнопка, письма) + документ §2.8 п. 10. B-11 в части уступки закрыто.
- 3.6 Утечка сумм защиты претендентам → **чинить** (сервер). Решения не требует.
- 3.7 Закрепление навсегда → **закрепление на срок** (длительность — настройка игры; предложено 3 недели). После срока город снова доступен для вызова со ставкой ≥ уровень + 1, суммарный режим сохраняется. Вопрос про столицу — открыт (см. ниже).
- 3.8 Вызов и ставка → **только капитан**. Код + документ §2.15. Ключ конверта — пока для всех участников (владелец не менял).
- 3.9 Дела по книге после взятия → **пересчитывать свободные стороны на выходах из взятого города**. Код.
- 3.10 Выбывшая команда → **оставить как задумано**: города в руины (есть), участники приглашаются в живые команды полноценными участниками. Механика перехода — уточняется.
- 3.11 Таблица лидеров → во время игры показывать **только взятые города** (без «на пути»). Код.
- 3.12 Уведомление об одобрении/возврате дела → **чинить**. Код.
- 3.13 Разрешение прохода → **сбрасывается при смене владельца города**. Пропуск как предмет торга (R-01) — отдельно, глава 8. Код + документ §2.14.
- 3.14 Смена ролей → **не чаще раза в неделю и только с одобрения администратора игры** (капитан запрашивает, админ подтверждает). Код + документ §2.15.
- 3.15 Тяжесть дела → **убрать поле совсем** (частота редко/обычно/часто уже есть и остаётся). Код + набор + документ. D-03 закрыто.
- 3.16 Тип сдачи «подтверждение» → **убрать**, остаются отчёт / фото / видео. Подтверждение адресата не нужно. D-04 (карточки благодарности) закрыто. Код + набор + документ.
- 3.17 Пустой список книг = любая книга → **чинить под документ**. Код.
- 3.18 Чек-лист готовности → **расширить**: капитан в каждой команде, не меньше двух участников, конверты назначены и распечатаны. Подтверждение почты в чек-лист не входит (обязательно по умолчанию). Код.
- 3.19 Попытки в заданиях → **растущая пауза для всех типов** (20 с, 1 мин, 5 мин, 15 мин, 1 ч, далее по часу; на задание; сброс при верном ответе). Две попытки и блокировка на сутки у выбора убираются, «снять блокировку» в поддержке не нужна. Код + документ §2.6.
- 3.20 Ничья по сроку → **по документу плюс дела**: столицы → одобренные дела → отражённые вызовы → сумма уровней защиты; номер команды никогда. «Хлеб городу» (+1 к защите за 5 дел) — решение отложено (глава 3). Код + документ §2.9.
