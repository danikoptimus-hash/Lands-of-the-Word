## Глава 2, раздел 5 (недосказанное и противоречивое)

- 5.4 Уровень после захвата → **ровно ставка**, сколько указали в вызове. Вызов состоит из N стихов: лишние выученные стихи не считаются, хранители отвечают на N, уровень нового города = N. Хотят больше — ставят больше в вызове. Код (сейчас max(N, сумма)) + документ.
- 5.6 Суммарный режим → **как в коде**: один стих одного участника = одна единица, всё суммируется. Из документа убрать фразу «каждому участнику свой отрывок».
- 5.7 Четырнадцать дней при очереди → **с момента, когда очередь дошла до команды**; отрывок для претендентов открывается тоже только в этот момент, не раньше. Владельцу письмо «на ваш город встали в очередь». Код + документ.
- 5.8 Сгоревший вызов → **чинить**: письмо хранителям, значок снимается сразу. Код.
- 5.10 Труд в днях → **специальной механики не делать**, участник прикладывает отчёт за следующий день к следующему делу. Правило «один день труда = одна сторона» из документа убрать.
- 5.11 Чужие проходы → **показывать команде чужие пройденные стороны там, где у неё открыт туман**, цветом той команды; сторона, пройденная двумя командами, красится пополам (как записано в документе §2.4). Код.
- 5.12 Число дел → в документе **одна рекомендация: чем больше дел, тем интереснее**; конкретные числа убрать (предупреждение в коде остаётся).
- 5.18 Неверный ключ конверта → **растущая пауза с каждой ошибкой**, как у заданий. Код + документ.
- 5.19 Лента уведомлений → **будет «Летопись»**, обсуждается в главе 4.
- 5.20 Суперадмин и содержимое игр → **править документ** под решения 13.09.
- 5.21 Второй рейс после возврата порта → **чинить**. Код.

Виды дел не регламентируются. У кого больше баллов к концу срока, тот владеет городом; при равенстве город остаётся у хранителей. Стихов в осаде нет.
