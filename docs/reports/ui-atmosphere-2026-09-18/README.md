# Оформление «игра, а не сайт»: было и стало по всем экранам

Решение владельца 18.09: убрать белые фоны и «офисные» блоки, спрятать пояснения за кнопки, оформить интерфейс материалами игры — пергамент, дерево, бронза, сургуч. Снимки сделаны на стенде с данными тестовой партии (команды «Моряки», «Берег», «Пустыня»; реальных людей нет). Слева — до правок, справа — после.
