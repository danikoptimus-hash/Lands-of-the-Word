# Текст Библии (Синодальный перевод)

Один файл на книгу: `<код книги>.json` (коды — как в `packages/domain/src/books.ts`, например `rut`, `gen`, `1sa`).

```json
{
  "code": "rut",
  "translation": "Синодальный перевод",
  "verseCounts": [22, 23, 18, 22],
  "chapters": [["1:1 текст", "1:2 текст", "…"], ["…"]],
  "genealogies": [{ "from": "4:18", "to": "4:22" }]
}
```

- `verseCounts` — число стихов в каждой главе по русской нумерации. Обязательно: по нему выдаются случайные отрывки для битв.
- `chapters` — текст стихов по главам (необязательно; если есть, отрывок показывается командам текстом). В `chapters[i][j]` — стих `i+1:j+1` без номера.
- `genealogies` — диапазоны родословий и списков, которые исключаются из случайного отрывка переключателем игры.

Пока нет файла книги, войну за её город объявить нельзя (игра скажет «текст книги ещё не загружен»).
Скрипт `scripts/import-bible.py` собирает эти файлы из текстового выгруза (одна строка = один стих: `Книга глава:стих текст`).
