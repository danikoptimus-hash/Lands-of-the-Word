# Картинки островков

Сюда кладутся нарисованные острова для моря вокруг поля: `islet-1.png` … `islet-6.png`.

Требования: PNG с прозрачным фоном, 1024×1024 или больше, вид сверху с лёгким наклоном (как у городов),
только остров с пляжем — без воды вокруг (отмель и волны рисует карта), без текста и рамок.

Пока файлов нет, островки рисуются из текстур местности (`apps/web/src/pages/Islets.tsx`).
