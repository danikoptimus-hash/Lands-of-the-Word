# Картинки островков

`islet-1.png` … `islet-6.png` — исходники (1254×1254, прозрачный фон, вид сверху с лёгким наклоном, как у городов; только остров с пляжем, без воды вокруг).
`islet-N.webp` — сжатые копии (до 2048 px, без увеличения), которые показывает карта. Чем крупнее исходник, тем резче остров на максимальном приближении: лучше 2048–4096 px. Контуры островов по прозрачности лежат в `packages/domain/src/isletShapes.ts`.

При замене картинок запустите из корня `python3 scripts/islet-shapes.py`: он пересчитает контуры и пересоберёт WebP.
