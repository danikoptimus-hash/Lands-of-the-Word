# Картинки островов

`islet-1.png` … `islet-6.png` — исходники (прозрачный фон, вид сверху с лёгким наклоном, как у городов; только остров с пляжем, без воды вокруг).
`islet-N.webp` — копии до 2048 px, которые показывает карта. Контуры островов по прозрачности лежат в `packages/domain/src/isletShapes.ts`.

Размер на карте: самый большой остров — около четверти площади главного острова, поэтому исходники нужны **4096×4096**,
а детали (деревья, камни) должны быть в масштабе поля: пальма не больше пальмы на картинке города.

При замене картинок запустите из корня `python3 scripts/islet-shapes.py`: он пересчитает контуры и пересоберёт WebP.
