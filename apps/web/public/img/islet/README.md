# Картинки островков

`islet-1.png` … `islet-6.png` — исходники (1254×1254, прозрачный фон, вид сверху с лёгким наклоном, как у городов; только остров с пляжем, без воды вокруг).
`islet-N.webp` — сжатые копии 1024 px, которые показывает карта. Контуры островов по прозрачности лежат в `packages/domain/src/isletShapes.ts`.

При замене картинок запустите из корня `python3 scripts/islet-shapes.py`: он пересчитает контуры и пересоберёт WebP.
