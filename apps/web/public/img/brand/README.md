# Логотип

`logo.png` — исходник (1254×1254, прозрачный фон). Остальные файлы сделаны из него скриптом и подключены:

- `logo-64/128/256/512.png` — шапка сайта, страница входа, письма;
- `../../favicon.ico`, `../../favicon-32.png` — иконка вкладки;
- `../../apple-touch-icon.png`, `../../icon-192.png`, `../../icon-512.png`, `../../icon-maskable-512.png`, `../../manifest.webmanifest` — иконка на экране телефона;
- `../../og-image.png` — картинка в предпросмотре ссылки в мессенджерах.

Чтобы заменить логотип, положите новый `logo.png` (квадрат, прозрачный фон) и перегенерируйте размеры (см. `scripts/brand-assets.py`).

Фоны: `bg-tile.webp` — замощение страниц (пергамент с гексами), `sea.webp` — исходник моря; `sea-512.webp` и `sea-1024.webp` — бесшовные плитки из него (зеркальная сборка 2×2, для обычной и высокой плотности пикселей), именно они используются на карте, `hero.webp` — панорама за страницей входа. Исходники PNG в истории репозитория.
