# Логотип

Сюда кладётся логотип игры. Ожидаемые файлы:

- `logo.svg` или `logo.png` — знак без текста, квадрат (для PNG — 1024×1024, прозрачный фон).
- `logo-wide.svg` / `logo-wide.png` — знак с надписью, горизонтальный (необязательно).

Требования: 1–2 цвета из палитры сайта (акцент `#C7742A`, тёмный `#1F1B16`, фон `#F6F4EF`),
простой силуэт, читаемый при 16×16, отступ около 10% по краям. Без фото, лиц и имён.

После загрузки файла подключаются иконка вкладки, иконка для телефона, шапка сайта, страница входа и письма.
